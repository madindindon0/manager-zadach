# Task Manager

Простое приложение для управления задачами.

## Запуск

1. Установите Python 3.x.
2. Запустите `gui.py`.
3. Добавляйте задачи через форму, удаляйте выбором в списке.

## Функциональность

- Добавление/удаление задач.
- Автосохранение в JSON-файл.

## Структура проекта

- `classes.py` — классы `Task` и `TaskManager` (логика и работа с файлом).
- `gui.py` — графический интерфейс на Tkinter.
- `tasks.json` — файл с сохранёнными задачами.
- `README.md` — описание проекта.

## Как использовать

1. Введите название задачи в поле **Название**.
2. Заполните **Описание**.
3. Укажите **Срок выполнения** в формате `ГГГГ-ММ-ДД`.
4. Нажмите **Добавить** — задача появится в списке и сохранится в `tasks.json`.
5. Выберите задачу в списке и нажмите **Удалить**, чтобы убрать её.

При следующем запуске задачи автоматически загрузятся из `tasks.json`.
